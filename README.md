# Java Challenges

Repositório dedicado ao treinamento de lógica de programação utilizando Java.

O objetivo é praticar:
- resolução de problemas;
- raciocínio lógico;
- estruturas de controle;
- algoritmos;
- estruturas de dados.

## Organização

- fundamentals: conceitos básicos da linguagem
- arrays: manipulação de vetores
- strings: processamento de textos
- algorithms: algoritmos clássicos
- data-structures: estruturas de dados

## Evolução

Este repositório registra minha evolução durante os estudos de Java e preparação para desafios técnicos.
