````md id="f4m8ty"
# Difference

## Problem Description

Read four integer values: **A**, **B**, **C**, and **D**.

Calculate the difference between the product of **A** and **B** and the product of **C** and **D** using the following expression:

```text
(A × B) - (C × D)
```

Store the result and print it in the required format.

---

## Input

The input consists of **four integer numbers**:

- `A`
- `B`
- `C`
- `D`

---

## Output

Print the message:

```text
DIFERENCA = value
```

where `value` is the result of the expression:

```text
(A × B) - (C × D)
```

> **Important:** Print a line break (`endline`) after the result.

---

## Formula

```text
DIFERENCA = (A × B) - (C × D)
```

---

## Sample Input 1

```text
5
6
7
8
```

### Sample Output 1

```text
DIFERENCA = -26
```

```
````
