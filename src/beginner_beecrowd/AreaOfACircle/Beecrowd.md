# Area of a Circle

## Problem Description

The formula to calculate the area of a circle is:

```text
A = π × R²
```

For this problem, consider:

```text
π = 3.14159
```

Calculate the area of the circle using the given formula.

---

## Input

The input contains a single **floating-point number** (double precision):

- `R` — the radius of the circle.

---

## Output

Print the message:

```text
A=value
```

where `value` is the calculated area with **exactly four digits after the decimal point**.

> **Important:** Use double precision variables and print a line break (`endline`) after the result to avoid a **Presentation Error**.

---

## Formula

```text
A = 3.14159 × R²
```

---

## Sample Input 1

```text
2.00
```

### Sample Output 1

```text
A=12.5664
```
