# Simple Product

## Problem Description

Read two integer values. Then, calculate the product of these values and store the result in the variable **PROD**.

Finally, print the value of **PROD**.

---

## Input

The input consists of **two integer numbers**:

- `A`
- `B`

---

## Output

Print the message:

```text
PROD = value
```

where `value` is the product of **A** and **B**.

> **Important:** Print a line break (`endline`) after the result to avoid a **Presentation Error**.

---

## Sample Input 1

```text
3
9
```

### Sample Output 1

```text
PROD = 27
```

---

## Sample Input 2

```text
-30
10
```

### Sample Output 2

```text
PROD = -300
```

---

## Sample Input 3

```text
0
9
```

### Sample Output 3

```text
PROD = 0
```
