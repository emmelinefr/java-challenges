# Sum of Two Numbers

## Problem Description

Read two integer variables, named **A** and **B**, calculate the sum of these two values, and assign the result to the variable **X**.

Print the value of **X** in the format shown below.

> **Important:** Print a line break (`endline`) after the result; otherwise, you may receive a **Presentation Error**.

---

## Input

The input consists of **two integer numbers**:

- `A`
- `B`

---

## Output

Print the letter **X** (uppercase), followed by a space, the equal sign (`=`), another space, and the value of **X**, in the following format:

```text
X = value
```

---

## Sample Input 1

```text
10
9
```

### Sample Output 1

```text
X = 19
```

---

## Sample Input 2

```text
-10
4
```

### Sample Output 2

```text
X = -6
```

---

## Sample Input 3

```text
15
-7
```

### Sample Output 3

```text
X = 8
```
