# Simple Sum

## Problem Description

Read two integer values, **A** and **B**. Then, calculate the sum of these values and store the result in the variable **SOMA**.

Finally, print the value of **SOMA**.

---

## Input

The input consists of **two integer numbers**:

- `A`
- `B`

---

## Output

Print the message:

```text
SOMA = value
```

where `value` is the sum of **A** and **B**.

> **Important:** Print a line break (`endline`) after the result to avoid a **Presentation Error**.

---

## Sample Input 1

```text
30
10
```

### Sample Output 1

```text
SOMA = 40
```

---

## Sample Input 2

```text
-30
10
```

### Sample Output 2

```text
SOMA = -20
```

---

## Sample Input 3

```text
0
0
```

### Sample Output 3

```text
SOMA = 0
```
